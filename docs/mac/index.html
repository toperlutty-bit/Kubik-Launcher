Kubik для Mac

← Kubik Mobile

Kubik Launcher пока работает только на Windows. Сам мод Kubik Client работает и на Mac: с меню на правый Shift, HUD, визуалами и Click GUI.

⬇ Скачать Kubik Client (.jar)

Для Minecraft 1.21.11 + Fabric. Подходит для Mac на Intel и Apple Silicon (M1–M4).

Установка

  1. Открой свой лаунчерПодойдёт любой лаунчер с поддержкой Fabric.
  2. Создай сборку Minecraft 1.21.11 с FabricВерсия игры 1.21.11, загрузчик модов Fabric.
  3. Добавь Fabric APIЭто обязательный мод. Скачать: Fabric API для 1.21.11.
  4. Добавь Kubik ClientПоложи скачанный kubik-client-1.21.11.jar в папку mods этой сборки.
  5. ИграйЗапусти игру и открой меню Kubik на правый Shift.

Сервера других версий (по желанию)

С модом ViaFabricPlus можно заходить на сервера любых версий (1.8, 1.12, 1.16, 1.20…), не меняя сборку.

  1. Скачай ViaFabricPlusViaFabricPlus для 1.21.11. Положи его в ту же папку mods.
  2. Выбери версиюВ игре нажми Kubik Launcher → Версия сервера и выбери версию сервера перед входом.

Если не знаешь, какой лаунчер использовать, рекомендуем Prism Launcher.

⚠ Что пока не работает на Mac

Подписки Plus / Elite выдаются через Kubik Launcher, а его на Mac пока нет. Поэтому без него доступны только бесплатные функции. Версия лаунчера для Mac в планах.

Если Mac не даёт открыть лаунчер

Открой Системные настройки → Конфиденциальность и безопасность, пролистай вниз и нажми «Всё равно открыть».
