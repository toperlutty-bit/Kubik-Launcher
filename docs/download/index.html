Как поставить только мод

Для обычного лаунчера Minecraft, TLauncher и любых других. Подходит для Windows, Mac и Linux.

  • Поставь Fabric для 1.21.11: скачай Fabric Installer, открой его, выбери версию 1.21.11 и нажми Install.
  • Положи мод в папку mods: скачай kubik-client-1.21.11.jar и положи в %appdata%\.minecraft\mods (Windows) или ~/Library/Application Support/minecraft/mods (Mac). Нет папки — создай.
  • Убери старый Kubik Client, если он там уже был: два мода Kubik сразу не запустятся. Fabric API отдельно не нужен — он уже внутри.
  • Запусти профиль fabric-loader-1.21.11 в лаунчере. Появится зелёное меню Kubik.
  • По желанию: ViaFabricPlus — для серверов других версий, тоже в mods.

Есть Prism Launcher или Modrinth App? Проще импортировать сборку: Add Instance → Import и вставь ссылку https://toperlutty-bit.github.io/Kubik-Launcher/downloads/Kubik.mrpack
